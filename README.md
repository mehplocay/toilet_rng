# Toilet RNG

Roblox game: flush your toilet, roll absurd drops, sell or display them, upgrade your toilet, and chase 1-in-100,000 server events.

- Design: [docs/GDD.md](docs/GDD.md)
- Setup / run in Studio: [docs/README-setup.md](docs/README-setup.md)
- Architecture notes: [docs/foundation.md](docs/foundation.md)
- Rules for the dev agent: [AGENTS.md](AGENTS.md)

Quick start: `rojo serve`, then connect from Roblox Studio with the Rojo plugin.
Checks: `rojo build -o build.rbxl`, `stylua --check src scripts`, `luau scripts/check-foundation.luau`.
