# Environment kit: import, units, rendering and streaming

Checked 2026-10-05. This extends `blender-roblox-pipeline.md`; it does not change the game's runtime settings.

- General mesh specifications still cap an individual mesh at **20,000 triangles** and require volume and watertight surfaces. The environment uses smaller per-design budgets, triangulates before export and validates each closed component. Intersecting shells are intentional; these are render meshes, not boolean-unioned collision hulls. [Creator Hub specifications](https://create.roblox.com/docs/art/modeling/specifications)
- The official Blender guide continues to prescribe **Z Forward / Y Up**, unit scale and Stud import. Existing exports use the same exporter with embedded PNGs. A live Blender API search corroborated `apply_scale_options`, `path_mode`, `embed_textures`, selection-only export and axis options; the version-specific 4.5 documentation endpoint did not load in this session. Installed Blender 4.5.10 successfully exercised these options in the local round trip. [Roblox Blender workflow](https://create.roblox.com/docs/art/blender), [Blender exporter API](https://docs.blender.org/api/main/bpy.ops.export_scene.html)
- The current DevForum announcement search result confirms importer conversion changes starting June 16, 2026. Its full page was blocked by a JavaScript challenge in this session; preserve the previously verified **Stud / Scale Factor 1** convention from the pipeline research. Do not introduce meter corrections. [Official change announcement](https://devforum.roblox.com/t/more-control-over-importer-custom-scale-factor-and-updated-unit-conversions/4644371)
- Current MeshPart reference still exposes `RenderFidelity` with plugin security and `MeshId` with restricted access. Configure mesh fidelity during Studio import/editing, retain uploaded templates, and clone them during later integration. No runtime property setters are added by this task. [MeshPart](https://create.roblox.com/docs/reference/engine/classes/MeshPart)
- Render fidelity options remain Automatic, Precise and Performance. Collision fidelity includes Box, Hull and PreciseConvexDecomposition. Start with **Automatic** rendering, non-colliding decorative meshes and separate simple walkable proxies; do not turn a joined arch into a colliding box across its opening. These are recommendations, not a claim of Studio performance testing. [RenderFidelity](https://create.roblox.com/docs/reference/engine/enums/RenderFidelity), [CollisionFidelity](https://create.roblox.com/docs/reference/engine/enums/CollisionFidelity), [Mesh collision](https://create.roblox.com/docs/parts/meshes)
- Streaming documentation recommends keeping models spatially compact. Atomic models arrive together; Persistent models are intended for rare needs, not for circumventing streaming. Keep each kit module separate; avoid merging the entire island into one Atomic/Persistent model. The existing 128/384 streaming radii remain untouched. Test distant scenery disappearance and graphics quality in Studio before choosing any changes. [Instance streaming](https://create.roblox.com/docs/workspace/streaming)
- **256 studs per dimension is this kit's conservative authoring ceiling**, not a newly asserted Roblox engine limit. The live BasePart reference did not expose a numerical maximum in its Size documentation. All delivered assets are much smaller than that pack ceiling, and no giant single-mesh island is exported. [BasePart](https://create.roblox.com/docs/reference/engine/classes/BasePart)

Acceptance boundary: FBX import/export in Blender verifies geometry, dimensions, atlas, closed components and base pivots. It cannot verify Studio axis correction, upload moderation, ownership permissions, Roblox collision generation or actual mobile rendering cost.
