# Native PlayerList and leaderstats

Checked 2026-10-06.

- [Current leaderboards guide](https://create.roblox.com/docs/players/leaderboards): lowercase leaderstats Folder drives in-server rankings; IntValue, NumberValue and StringValue are supported. Child IsPrimary BoolValue=true puts a stat first; child Priority NumberValue orders other columns (higher first). New Friends/Global leaderboard views require separate registered ordered data stores; this task provides session stats only.
- [NumberValue](https://create.roblox.com/docs/reference/engine/classes/NumberValue) / [official source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/NumberValue.yaml): IEEE-754 double, exact integer range through 2^53 (9,007,199,254,740,992). Coins cap 9,000,000,000,000,000 is below it. [IntValue](https://create.roblox.com/docs/reference/engine/classes/IntValue) is signed int64, not int32; it also supports this cap, though Luau arithmetic loses exactness above 2^53. Keep Coins as NumberValue for numeric sorting; Rebirths uses IntValue; Rarest uses StringValue containing the saved rarity.
- [StarterGui API](https://create.roblox.com/docs/reference/engine/classes/StarterGui) / [disable-UI guide](https://create.roblox.com/docs/players/disable-ui): client SetCoreGuiEnabled(PlayerList,true) enables the native list. Tab/topbar visibility belongs to Roblox, and Enabled is not the same as expanded/collapsed. Enable once with bounded startup retries; do not force it open each heartbeat.
- Roblox's [archived official PlayerList code](https://github.com/Roblox/Core-Scripts/blob/master/CoreScriptsRoot/Modules/PlayerlistModule.lua) sorts rows by the first stat's numeric value and recognizes supported value objects. This is historical supporting evidence, not a contract for current CoreScripts' tie-breaking/formatting.
- Exact suffix spelling/rounding is not documented as a stable API. Roblox-owned [PlayerList update thread](https://devforum.roblox.com/t/playerlist-updates/434738) and [abbreviation request](https://devforum.roblox.com/t/leaderstat-numbers-are-forced-to-be-abbreviated/406246) demonstrate native numeric abbreviations. Leave 1,200,000 and 3,400,000,000 numeric; expect compact million/billion labels, with case/rounding and very-large suffixes owned by the current client. Do not replace Coins with formatted strings to force 1.2M/3.4B: that compromises numeric ordering. Live exact labels at those values and 9e15 remain QA.
- [Teams API](https://create.roblox.com/docs/reference/engine/classes/Team) and the official archived code show team-aware lists. Our project creates no Teams; plot spawns are Neutral=true, AllowTeamChangeOnTouch=false. No artificial teams or grouping overrides are introduced.

Hidden data: no documented per-stat hiding flag is used. Only Coins/Rebirths/Rarest are direct ValueBase children; IsPrimary/Priority are child metadata, not extra columns. Inventory, pending income, admin/session/settings data never enter leaderstats. Unchanged values are not assigned; polling is once per second. Profile loss/removal destroys the folder. Forced admin previews already bypass natural Rarest recording.

The native rendering, actual sort/abbreviation thresholds and overlay layout require Studio/device confirmation. Studio execution was blocked by the tool approval policy in this session.
