# Cosmetic rendering and settings

Checked 2026-10-05 before implementation.

- [Trail](https://create.roblox.com/docs/reference/engine/classes/Trail): render between two character attachments; short lifetime and no external texture required.
- [ParticleEmitter](https://create.roblox.com/docs/reference/engine/classes/ParticleEmitter): reuse the project's engine-bundled sparkle texture from `Config/Assets`, keep a small rate, and create emitters only for server-confirmed owners. Character descendants naturally disappear on respawn; reapply entitlements on CharacterAdded.
- [BillboardGui](https://create.roblox.com/docs/reference/engine/classes/BillboardGui): overhead VIP label uses the character head as Adornee and bounded MaxDistance; no admin/official badge.
- [TextChatService](https://create.roblox.com/docs/reference/engine/classes/TextChatService) and [ChatWindowMessageProperties](https://create.roblox.com/docs/reference/engine/classes/ChatWindowMessageProperties/PrefixTextProperties): use client-only `OnChatWindowAdded` with `ChatWindowConfiguration:DeriveNewMessageProperties()` to decorate the final chat-window PrefixText. The client looks up the sender's server-replicated VIPStar attribute; prefix only, never replace/filter message text or default whisper/team prefixes. Keep one callback registration; do not read callback members ([DevForum write-only callback report](https://devforum.roblox.com/t/playerchatted-not-firing-on-the-client-for-the-local-player-with-textchatservice/3652658)). Current docs say platform-integrated chat disables developer `OnIncomingMessage` callbacks, so this implementation uses the documented window callback instead. Live platform chat customization still needs verification before selling the chat benefit.
- [Rojo docs](https://rojo.space/docs/v7/getting-started/installation/) and [StyLua docs](https://github.com/JohnnyMorganz/StyLua): use installed CLI tools for build and formatting. Selene's Roblox standard library availability is checked locally.

Plot picker accepts only configured palette IDs on the server with confirmed CustomPlotColor ownership. Persist preference separately from entitlement; a saved tint never grants ownership. Tint lawn/borders only, restore builder colors on owner departure/default/unowned state. Skip animation is a saved free setting: instant static world drop plus concise result text, no toilet wobble/flight or local celebration animation. This does not shorten gameplay cooldowns.
