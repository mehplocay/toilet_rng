# Tiered reveal API review

Checked 2026-10-06. Presentation only; no new asset IDs or physics manipulation.

- [Rich text](https://create.roblox.com/docs/ui/rich-text): enable RichText per TextLabel, use a font color tag for the compact golden NEW prefix, and escape catalog names before concatenating markup.

- [TweenService](https://create.roblox.com/docs/reference/engine/classes/TweenService) / [Tween](https://create.roblox.com/docs/reference/engine/classes/Tween): cancel owned tweens on cleanup; a newer tween of the same property replaces the old one. Mythic uses short expansion, a longer suspended expansion, then release. ClockTime transitions use an owned, cancelled tween and shared leases to restore overlapping local/server effects.
- [ColorCorrectionEffect](https://create.roblox.com/docs/reference/engine/classes/ColorCorrectionEffect), [BlurEffect](https://create.roblox.com/docs/reference/engine/classes/BlurEffect), [Lighting](https://create.roblox.com/docs/reference/engine/classes/Lighting), [Sky](https://create.roblox.com/docs/reference/engine/classes/Sky): local effects live under Lighting. Use temporary color correction, desktop-only blur size 4, ClockTime and native StarCount. Reuse the existing Sky and restore its star count, or destroy a locally created fallback Sky. No skybox texture IDs. Engine quality/Atmosphere can affect visibility; verify in Studio.
- [RunService](https://create.roblox.com/docs/reference/engine/classes/RunService): camera controls run at priority 200. Undo our last camera offset at 199, add a bounded offset at 201, and unbind on every exit. Never change CameraType or capture movement. Rendering waits for callbacks: keep camera work constant and short.
- [ViewportFrame](https://create.roblox.com/docs/ui/viewport-frames): one local camera and one cloned catalog model per active cinematic; pending entries contain data only. Do not expect workspace particles or post-processing inside the viewport. Existing template builder/framing is reused.
- [UIGradient](https://create.roblox.com/docs/reference/engine/classes/UIGradient/Enabled): set color/transparency sequences once (at most three stops here); animate Offset/Rotation. Celestial removes the name's text stroke before its shimmer. [UIStroke](https://create.roblox.com/docs/reference/engine/classes/UIStroke) supplies ring outlines. The [Roblox UIGradient announcement](https://devforum.roblox.com/t/uigradient-live/404831) was checked; its current body is inaccessible to this browser.
- [ParticleEmitter](https://create.roblox.com/docs/reference/engine/classes/ParticleEmitter) / [performance guidance](https://create.roblox.com/docs/performance-optimization/improve): transparent overdraw and particle density matter on mobile. These reveals use fixed UI sprites, zero new world emitters, no per-frame instance allocation, one viewport and a 30 Hz visual update budget. Device timing must be measured with the engine, not inferred from CLI execution.
- [Release 741](https://devforum.roblox.com/t/release-notes-for-741/4906281) was attempted before final validation; the site returned a JavaScript/anti-bot gate. Current Creator API pages were accessible. No claim of release-note compatibility beyond the inspected API contracts.
- Tool references: [Rojo build](https://rojo.space/docs/v7/getting-started/new-game/), [StyLua check](https://github.com/JohnnyMorganz/StyLua), [Selene standard libraries](https://github.com/kampfkarren/selene/blob/main/docs/src/usage/std.md). Windows checkout uses CRLF; validate with `stylua --check --line-endings Windows src scripts`. Selene cannot load the configured Roblox library in this environment.
- Existing audit gate requires serialized modern chat/default channels/window. This checkout omitted that documented project block; restored it without changing recipients or server rules. [TextChatService](https://create.roblox.com/docs/reference/engine/classes/TextChatService) marks ChatVersion deprecated; retain its modern value for the existing build gate/legacy-place compatibility, and enable channels/window in Rojo rather than runtime secured-property writes. See [earlier chat research](chat-native-system-messages.md).
