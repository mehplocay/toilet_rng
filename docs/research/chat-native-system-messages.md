# Native chat system messages

Checked 2026-10-06.

- [TextChannel API](https://create.roblox.com/docs/reference/engine/classes/TextChannel) and [official source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/TextChannel.yaml): DisplaySystemMessage is client-only, local to that user, and does not filter/localize its text. A server call cannot broadcast it. Use a validated server RemoteEvent followed by the client method. Only authored catalog text and sanitized account identity enter this flow; no user free text.
- [TextChatService](https://create.roblox.com/docs/reference/engine/classes/TextChatService) and [official source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/TextChatService.yaml): CreateDefaultTextChannels creates RBXGeneral/RBXSystem. Their default decorators differ; RBXSystem applies gray/red styling. ChatVersion is deprecated for new experiences, but an old serialized LegacyChatService value disables modern chat. Configure modern chat/default channels through the Rojo place rather than trying to write secured properties from a running script.
- [Chat window](https://create.roblox.com/docs/chat/chat-window): rich text is supported; General and System share the General tab. Prefer RBXGeneral for colored authored finds, retain RBXSystem as fallback. Do not replace existing channel decorators or the VIP callback.
- [Roblox staff channel-tab announcement](https://devforum.roblox.com/t/channel-tabs-ui-gradient-now-available-in-textchatservice/3249560) confirms shared General/System tabs and local system-message usage. [Reported color issue](https://devforum.roblox.com/t/textchatservice-system-message-font-color-help/2866522) motivated checking complete RGB/hex markup; the API and official chat examples remain authoritative.
- [Release 741](https://devforum.roblox.com/t/release-notes-for-741/4906281), September 30: platform chat/history changes continue; this implementation does not depend on replay/history APIs. The official release index was checked; its release-detail fetch was unavailable.
