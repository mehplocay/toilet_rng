# Rare drop presentation / chat / player list

Checked 2026-10-05. No external IDs added.

- [Chat window documentation](https://create.roblox.com/docs/chat/chat-window): system announcements use **TextChannel:DisplaySystemMessage on the receiving client**, normally RBXGeneral. There is no TextChatService:DisplaySystemMessage. Use an outbound-only remote; never accept user-authored system-message strings. The new path does not assign chat callbacks or compete with VIPChat.
- [TextChannel reference](https://create.roblox.com/docs/reference/engine/classes/TextChannel), [rich text](https://create.roblox.com/docs/ui/rich-text), [DevForum styling discussion](https://devforum.roblox.com/t/how-to-style-messages-using-textchanneldisplaysystemmessage/2459336): rich text may format system messages. System text is authored from the catalog and a restricted account username, not arbitrary text/DisplayName. Escape markup before interpolating.
- [Player reference](https://create.roblox.com/docs/reference/engine/classes/Player): use IsFriendsWithAsync; IsFriendsWith is deprecated. This call yields. One serial worker bounds outstanding lookups; revalidate player lifetime, profile lease, TTL and recipient preference after every yield. Friendship failures do not fall back to a server broadcast.
- [Leaderboards](https://create.roblox.com/docs/players/leaderboards): leaderstats must be lowercase, with value children. IsPrimary marks Coins as the primary stat. [DevForum abbreviation discussion](https://devforum.roblox.com/t/how-do-you-abbreviate-your-leaderstats/657722) highlights StringValue sorting difficulties. Preserve numeric server Coins; use a custom client list with explicit numeric sorting and K/M/B/T/Qa formatting. [StarterGui](https://create.roblox.com/docs/reference/engine/classes/StarterGui) supports disabling/restoring CoreGuiType.PlayerList. No private inventory/profile is replicated by this service.
- [ViewportFrames](https://create.roblox.com/docs/ui/viewport-frames): a dedicated CurrentCamera renders the item template; shared Items.Build supplies the same imported template or primitive fallback as the world. [Model](https://create.roblox.com/docs/reference/engine/classes/Model) bounding box/pivot frame the model; viewport lighting is explicitly configured.
- [RunService](https://create.roblox.com/docs/reference/engine/classes/RunService/BindToRenderStep): camera-adjacent render priorities permit a brief local shake, unbound on finish/skip/destruction. Restore only the transform this effect wrote, never a stale camera or a replacement camera. [Post processing](https://create.roblox.com/docs/environment/post-processing-effects): own local ColorCorrectionEffect fades to neutral then is destroyed; shared Lighting properties are untouched.
- Reviewed [release note index](https://devforum.roblox.com/c/updates/release-notes/62) and [Creator release index](https://create.roblox.com/docs/release-notes); indexes provided no detailed current notes through the reader. No additional platform-change claim is made. Current class references above govern the APIs used.
- [StyLua](https://github.com/JohnnyMorganz/StyLua) supports Luau and check mode. Rojo documentation fetch was unavailable; existing project/build workflow retained and checked locally.

Operational limits: friendship service/cache freshness and engine rendering require Studio testing. If chat channels do not exist yet, cosmetic announcements are dropped rather than queued indefinitely. Cosmetic announcement throttling never delays or changes an item grant or luck refresh.
