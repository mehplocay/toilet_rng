# Audio wiring research — 2026-10-06

Sources checked before integration; all runtime changes retain the existing Sound API.

- [Sound API](https://create.roblox.com/docs/reference/engine/classes/Sound) and [official source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/Sound.yaml): SoundId is an audio ContentId (`rbxassetid://` plus the uploaded numeric ID). Looped repeats at the end; Ended does not fire for loops or early stops. IsLoaded/Loaded identify readiness. Pause preserves TimePosition; Resume continues it. Keep mute fades ahead of Pause and begin loop attacks after loading.
- [Sound groups](https://create.roblox.com/docs/sound) and [SoundGroup API](https://create.roblox.com/docs/reference/engine/classes/SoundGroup): nonpositional background sounds belong under SoundService; nested groups mix sound volume and effects. Retain separate Music, SFX and Ambience buses. Cue/class gains multiply the selected slider; ambience receives its own duck gain.
- [ContentProvider](https://create.roblox.com/docs/reference/engine/classes/ContentProvider) and [official source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/ContentProvider.yaml): PreloadAsync yields, accepts Sound instances, and reports AssetFetchStatus per content request. An individual load failure does not throw out the whole batch. Spawn workers instead of blocking boot, retain silent short-SFX holders, check music status/IsLoaded with a deadline, and bound workers if a fetch hangs. Preloading cannot override asset permissions or guarantee network latency.
- [TweenService](https://create.roblox.com/docs/reference/engine/classes/TweenService) and [EasingStyle](https://create.roblox.com/docs/reference/engine/enums/EasingStyle): tween numeric volumes; Sine with InOut gives a smooth release. Destroy cancelled voices on tween completion, rather than a timer that might precede the last engine volume update. The 20 ms setting is a target; engine frame/audio scheduling needs audible verification.
- [Audio assets](https://create.roblox.com/docs/audio/assets) and [asset privacy](https://create.roblox.com/docs/projects/assets/privacy): imported audio starts private and must pass moderation. The separate opt-in Asset Privacy setting concerns images/decals/meshes, not audio. Verify production universe access in Creator Hub's experience Permissions page; restricted assets can be granted through asset Permissions → Experiences using the universe ID. Same-group ownership is the intended setup here, but the JSON upload notes do not prove effective permissions or moderation.
- [Same-group audio permission bug](https://devforum.roblox.com/t/unable-to-give-an-experience-permissions-to-use-an-audio-that-are-both-owned-by-the-same-group/2849723) and [Roblox staff troubleshooting](https://devforum.roblox.com/t/audio-assets-which-are-owned-by-the-group-are-not-available-to-games-within-the-same-group/2790633/14): group ownership alone has historically not guaranteed playback. Explicitly inspect/bulk-grant the production experience's audio access and test in a published server. Do not infer access from an uploader's Studio preview.
- [Creator updates](https://create.roblox.com/updates) and [release notes 720](https://create.roblox.com/docs/release-notes/release-notes-720) were consulted alongside the current API reference. No migration of this existing mixer to the newer AudioPlayer/wire objects is required for this task; current Sound documentation still exposes the APIs used here. This is not an exhaustive audit of every engine release.
- [Rojo v7 docs](https://rojo.space/docs/v7/) and [StyLua documentation](https://github.com/JohnnyMorganz/StyLua): use the existing project build and Luau formatting tools; no toolchain upgrades.

Unverified externally: all 53 assets' moderation status, Dreadlight Studio ownership versus the production universe owner, effective universe grants, and Roblox transcoding/playback on desktop/mobile. No credentials or private upload metadata were sent to web tools.
