# Rebirth single-click input and server validation

2026-10-06, feature/rebirth-click. Sources checked before implementation.

- [GuiButton.Activated](https://create.roblox.com/docs/reference/engine/classes/GuiButton/Activated) documents mouse press/release, mobile touch release and console A/cross activation. Use the existing Components.Button Activated connection; no custom input-duration listeners are needed.
- [GuiObject.Interactable](https://create.roblox.com/docs/reference/engine/classes/GuiObject#Interactable) disables pressing/clicking. Set the local pending guard and update Interactable before FireServer; do not use clickCount as authority.
- [Client/server security](https://create.roblox.com/docs/scripting/security/client-server-boundary) requires server type/value/state validation and server rate limiting for client-triggered work. The client submits only expectedLevel. Existing finite-generation, wallet, fresh-flush, max-level, numeric-bound and save guards remain authoritative.
- [Debounce patterns](https://create.roblox.com/docs/scripting/debounce) supports guarding repeated activations. Here the guard lasts until the Rebirth result, rather than an arbitrary input timer. State snapshots and response timeouts do not unlock it; a timeout requests state once and never resends a rebirth. After a rejection, retry pacing derives from Config.Remotes.Limits.Rebirth.Refill and shows PLEASE WAIT without a countdown or automatic retry.
- [DevForum duplicate Activated report](https://devforum.roblox.com/t/guibuttonactivated-firing-multiple-times/1655841) is a historical symptom report, not an API guarantee. [Release 589](https://devforum.roblox.com/t/release-notes-for-589/2520377) provides historical Interactable context; current Creator API docs are the behavioral source. The [release index](https://create.roblox.com/docs/release-notes) exposed only its documentation index to the browser, so no current release-specific guarantee is claimed.
- [Luau library](https://luau.org/library/) documents select/finite-number checks used by existing payload validation. No client elapsed time or reward data is accepted.
- [Rojo build](https://rojo.space/docs/v7/getting-started/new-game/#building-your-place) supports binary place output through .rbxl; [StyLua](https://github.com/JohnnyMorganz/StyLua) documents formatting/check mode; [Selene CLI](https://kampfkarren.github.io/selene/cli/usage.html) supports selected-file linting. Run existing project checks without altering unrelated source.

The server had no duration validation to remove. Expected-level compare-and-swap plus its existing one-token/0.2-per-second bucket prevents duplicate rebirths even after an old request is replayed when the next gate becomes eligible. Headless mocked-engine tests exercise actual production handlers, including delayed saves; real device hit-testing remains a Studio check. RebirthHold audio assets/IDs are retained as dormant provenance/mixer slots, with no UI caller.
