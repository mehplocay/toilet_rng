# Auto-Flush and pass fulfillment

Checked 2026-10-05 before implementation. The explicit task catalog takes precedence over the proposal's different cosmetics/prices and its no-permanent-speed-pass recommendation: Sparkle Trail 49, VIP Star 59, Custom Plot Color 79, Fast Flush 99 (-20% cooldown). Auto-Flush is free after 100 lifetime successful flushes. No paid luck/products ship.

- [Passes](https://create.roblox.com/docs/production/monetization/passes): privileges belong on the server; use `UserOwnsGamePassAsync` on join and Roblox's server `PromptGamePassPurchaseFinished` event for immediate entitlement fulfillment. Passes are permanent platform entitlements, not consumable developer-product receipts. Rejoining recovers interrupted purchases without adding items or currency.
- [MarketplaceService API](https://create.roblox.com/docs/reference/engine/classes/MarketplaceService): current API exposes `GetProductInfoAsync`; `GetProductInfo` is deprecated. Use `Enum.InfoType.GamePass`. No custom client completion event grants ownership. Verified ownership survives transient API failures and late negative results in the current session; unavailable initial checks grant nothing. Periodic and manual refresh retry recovery.
- [Regional pricing](https://create.roblox.com/docs/production/monetization/regional-pricing): query the current user's price on the client; do not present a configured base price as the live purchase price. ID 0 never prompts, base price is labeled planned, and metadata failures disable buying.
- [DevForum cache reports](https://devforum.roblox.com/t/promptgamepasspurchaseuserownsgamepassasync-not-working/3785874) flag negative ownership caching and web purchases during a session. Treat these as reports, not an API guarantee; recheck periodically, offer manual refresh, and always recheck on join. [Earlier cache discussion](https://devforum.roblox.com/t/update-the-userownsgamepassasync-cached-value-when-promptgamepasspurchasefinished-fires/369425) reinforces avoiding a stale negative overwriting a completed server purchase.
- [Platform recap, June 1-5 2026](https://devforum.roblox.com/t/weekly-recap-june-1-5-2026/4670282): product-info creator group `ID` can be 0. Do not infer validity or entitlement from creator fields. API reference checked for current supported methods; live platform behavior still needs published-place tests.

Auto-Flush is session-only, default OFF, uses the manual flush reservation/cooldown/award path, and switches OFF on missing/dead character or leaving the existing 14-stud toilet range. Polling checks cooldown before consuming a Flush rate-limit token, preserving the fastest toilet's intended interval. No reconnect/AFK bypass or second grant path.
