# Roblox image and decal IDs

For UI images, Roblox's `ImageLabel.Image` accepts the asset ID of an uploaded decal or image, commonly written as `rbxassetid://<id>`. The Creator Hub assigns a unique asset ID to an imported image. This supports storing the uploaded decal IDs in `Assets.luau` in the same format as the existing icon mappings.

Sources checked 2026-10-08:

- https://create.roblox.com/docs/projects/assets
- https://create.roblox.com/docs/reference/engine/classes/ImageLabel/ImageContent
