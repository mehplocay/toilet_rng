# World models research — 2026-10-05

## Runtime meshes, access and caching

- [InsertService API](https://create.roblox.com/docs/reference/engine/classes/InsertService) and [official API source](https://github.com/Roblox/creator-docs/blob/main/content/en-us/reference/engine/classes/InsertService.yaml): `CreateMeshPartAsync(contentId, CollisionFidelity, RenderFidelity)` yields, can throw, and has Basic capability / no plugin security. MeshId cannot simply be assigned by a game script. Use `pcall`, Box collision and Automatic rendering at creation.
- [Release 626](https://devforum.roblox.com/t/release-notes-for-626/2996431) changed script access; early rollout reports in that thread were pending-feature failures. [Follow-up performance report](https://devforum.roblox.com/t/release-notes-for-626/2996431?page=2) reports creation substantially more expensive than cloning. This is anecdotal, not a timing guarantee. Decision: one attempt per configured asset per server, bounded concurrent startup warming, clone templates from ServerStorage; never download on a flush or refresh.
- [Asset privacy](https://create.roblox.com/docs/projects/assets/privacy): restricted meshes/images need experience permission. Upload under the intended owning user/group, grant the intended experience access to both mesh and palette, and wait for moderation. A public model/container ID is not its MeshId. Do not confuse LoadAsset's ownership rules with mesh content permission or assume Studio creator access proves published-server access.
- [ContentProvider](https://create.roblox.com/docs/reference/engine/classes/ContentProvider): `PreloadAsync` yields and reports per-content status. Cache only after successful mesh/palette preload; catching an exception alone does not detect all download failures. Server preloading does not warm every client's graphics cache. Missing configuration, denied access, moderation and network failures retain primitive geometry, with no repeated request storm.
- [Mesh customization](https://create.roblox.com/docs/parts/meshes), [MeshPart API](https://create.roblox.com/docs/reference/engine/classes/MeshPart): apply the atlas via TextureID, leave Color white and avoid competing SurfaceAppearance. Box is inexpensive; precise decomposition is inappropriate for decoration. Automatic allows distance-based LOD. RenderFidelity is restricted as a runtime property: pass fidelity into creation instead of assigning it later.
- [Streaming](https://create.roblox.com/docs/workspace/streaming): StreamingEnabled belongs to Workspace, not MeshPart, and is configured in Studio/Rojo, not switched on by a running script. Use small Atomic prop models; do not make the entire hub/plots Persistent or Atomic. Far silhouettes may stream away. The atmospheric sky/cloud layer supplies the horizon independently. Anchored decoration disables collision, touch and query; floors remain collidable.
- [Model](https://create.roblox.com/docs/reference/engine/classes/Model), [BasePart](https://create.roblox.com/docs/reference/engine/classes/BasePart), [SurfaceGui](https://create.roblox.com/docs/reference/engine/classes/SurfaceGui): explicit ground pivots keep clone placement consistent; independent flat sign faces avoid stretching text across a whole joined sign mesh. SurfaceGui distance limits reduce distant UI cost.

## Terrain and mobile cost

- [Terrain API](https://create.roblox.com/docs/reference/engine/classes/Terrain): FillBlock/FillBall are convenient bounded solid-volume stamps. WriteVoxels accepts matching 3D material/occupancy arrays, occupancy 0–1, at resolution 4 with a grid-aligned Region3. Water uses Enum.Material.Water; color, reflectance, transparency and wave properties are terrain-wide. Decoration/GrassLength are not scriptable.
- [Terrain generation experience](https://devforum.roblox.com/t/infinite-procedurally-generated-world-using-roblox-terrain/4179544), [performance request](https://devforum.roblox.com/t/optimizations-and-asynchronous-methods-for-terrain/3964467): writes can cause frame spikes. Decision: finite island, coarse 4-stud voxel field, bounded chunks and a yield between chunks, once before player assignment. No terrain updates in gameplay loops. Flatten the playable core; keep hills outside plots. Avoid thousands of FillBlock calls, enormous voxel arrays, or clearing unrelated Terrain.

## Sky and lighting

- [Lighting](https://create.roblox.com/docs/reference/engine/classes/Lighting), [Atmosphere](https://create.roblox.com/docs/reference/engine/classes/Atmosphere), [Sky](https://create.roblox.com/docs/reference/engine/classes/Sky): warm ClockTime/ColorShift_Top, colorful ambient, a low-density blue atmosphere, restrained bloom and color correction produce depth without an external skybox ID. Keep default engine sky textures, modest sun size and no daytime stars. LightingStyle/quality preference are authoring properties, set through Rojo. Do not assign deprecated Technology at runtime.
- [Dynamic clouds](https://create.roblox.com/docs/environment/clouds): Clouds render under Terrain; Cover and Density control coverage/opacity. Use one sparse layer plus a small number of static CloudPuffs props. No server animation loop, stacked transparent spheres or shadow-casting local lights.

## EditableMesh alternatives

- [EditableMesh](https://create.roblox.com/docs/reference/engine/classes/EditableMesh), [AssetService](https://create.roblox.com/docs/reference/engine/classes/AssetService): editable content has additional published-experience opt-in/verification, permissions and device memory constraints. AssetService:CreateMeshPartAsync(Content, options) is an alternative creation API; EditableMesh is unnecessary for immutable uploaded artwork.
- [Roblox geometry-team update](https://devforum.roblox.com/t/studio-beta-introducing-skinning-and-facs-data-support-for-editablemesh-objects/3731147), [memory/replication discussion](https://devforum.roblox.com/t/editablemeshes-capped-at-8-on-client-vs-much-larger-cap-on-server/3644678): editable replication and budgets have been active development areas. Do not assume server-generated editable objects replicate as static uploaded meshes. Decision: uploaded MeshParts and primitive fallbacks only; no EditableMesh dependency.

## Tooling

- [Rojo project format](https://rojo.space/docs/v7/project-format/): declare Workspace/Lighting authoring properties in `$properties`; verify with `rojo build -o build.rbxl`.
- [StyLua](https://github.com/JohnnyMorganz/StyLua): format Luau sources and check only owned changes to avoid rewriting the concurrent UI session.
- [Selene](https://github.com/Kampfkarren/selene): repository Roblox standard library availability determines whether lint can run. Headless checks mock engine boundaries and do not certify engine rendering, mesh permissions or mobile frame time.
