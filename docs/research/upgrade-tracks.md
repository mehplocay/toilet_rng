# Permanent coin upgrades (2026-10-05)

- [Creator security boundary](https://create.roblox.com/docs/scripting/security/client-server-boundary): validate types, finite bounded values, ownership/session and server prices; enforce server token buckets. `BuyUpgrade(trackId, expectedLevel)` accepts no price, amount or extra arguments. The level is a compare-and-swap precondition, so replay cannot purchase another level.
- [GlobalDataStore](https://create.roblox.com/docs/reference/engine/classes/GlobalDataStore): UpdateAsync may replay its transform and the callback cannot yield. Keep purchases outside transforms; snapshot coins and levels together through the existing session-owned save path. No network, task wait or persistence call occurs between checking and debiting a purchase.
- [DevForum race discussion](https://devforum.roblox.com/t/question-about-race-condition-w-remoteevent/3297723) and [Luau compatibility](https://luau.org/compatibility/): the ordinary serial coroutine model supports a non-yielding transaction; this is not a cross-Actor or cross-server lock. Existing DataService leases remain mandatory. Regression tests deliberately suspend saves, replay requests and retry committed writes.
- [TweenInfo](https://create.roblox.com/docs/reference/engine/datatypes/TweenInfo): repeats and reversal extend total tween time. Six forward/reverse legs require twelve segments, so the bowl uses `duration/12`; item flight uses duration directly. Both use `min(0.9, cooldown*0.8)`.
- [task](https://create.roblox.com/docs/reference/engine/libraries/task): waits/delays are scheduler operations, not an exact frequency guarantee. Auto uses server clock deadlines, one roll per wake, and the manual cooldown. There is no catch-up burst after a stalled frame.
