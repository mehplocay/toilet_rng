# Sound coverage research

Checked 2026-10-06 before/while extending the existing Sound mixer. No asset IDs or external audio were sourced.

- [Sound API](https://create.roblox.com/docs/reference/engine/classes/Sound): SoundId, PlaybackSpeed, Looped, Ended and IsLoaded remain documented. Playback speed affects both pitch and duration. Ended is not a loop cancellation mechanism; explicitly destroy stopped voices and bound inaccessible one-shots with timers. The dormant RebirthHold mixer slot retains generic stop/watchdog support; the ambient loop has a load deadline.
- [SoundGroup API](https://create.roblox.com/docs/reference/engine/classes/SoundGroup): explicitly assign SoundGroup. Child-bus and source gains combine, so keep ambience under the SFX group and duck its child bus without overriding the user's slider/mute. Music ducking targets only the music group, independent of playlist deck fades.
- [TweenService API](https://create.roblox.com/docs/reference/engine/classes/TweenService): retain cancellation of the preceding property tween before changing the mix target. Independent stinger/event deadlines prevent an earlier ending from releasing a later duck.
- [ProximityPromptService](https://create.roblox.com/docs/reference/engine/classes/ProximityPromptService), [ProximityPrompt](https://create.roblox.com/docs/reference/engine/classes/ProximityPrompt): central PromptTriggered handles prompt activation; ActionText/ObjectText, parent and activation distance control the local coming-soon prompt. No gameplay remote is needed for its toast/bonk. Collect/flush success still follows the server result.
- [GuiObject](https://create.roblox.com/docs/reference/engine/classes/GuiObject): Interactable=false prevents a GuiButton being pressed/clicked. Do not re-enable an unavailable purchase just to hear feedback. [BasePlayerGui](https://create.roblox.com/docs/reference/engine/classes/BasePlayerGui) documents GetGuiObjectsAtPosition, with a UserInputService pointer-position example; use the visible GUI stack to provide disabled feedback without invoking the button action.
- [Player](https://create.roblox.com/docs/reference/engine/classes/Player), [Players](https://create.roblox.com/docs/reference/engine/classes/Players): local character readiness and replication are distinct from profile receipt. Arrival waits for a character root and loaded audio preferences; successive character identities permit respawn feedback.
- [Official Audio API release announcement](https://devforum.roblox.com/t/roblox-audio-api-exits-beta-enhanced-sound-controls-now-available/3153454) and [current release-notes index](https://devforum.roblox.com/c/updates/release-notes/62) were checked; this browser received the DevForum JavaScript/verification wall. No new release behavior is assumed from inaccessible text. Current Creator API references remain the basis for the existing Sound/SoundGroup path. The [previous audio research](audio.md) records the compatibility decision and known permission/deployment concerns; no migration to an AudioPlayer graph is needed for this task.
- [Rojo build](https://rojo.space/docs/v7/getting-started/new-game/) documents binary .rbxl output; [StyLua](https://github.com/JohnnyMorganz/StyLua) covers Luau formatting/checks. [Selene Roblox guide](https://kampfkarren.github.io/selene/roblox.html) requires Roblox std support. Installed Selene 0.31.0 reports only validateConfig capability, has no generate-roblox-std subcommand, and cannot resolve std=roblox. Report this tooling limitation rather than replacing the project's lint configuration or pretending that lint ran.

Project-specific conclusions: Sell.Coins is a wallet balance; BuyPass.Success is also true when a prompt opens. Confirmed State deltas and exact existing pass-result status messages therefore drive semantic audio. These are repository protocol findings, not Roblox API guarantees. Empty assets are deliberately silent, and all game rewards remain server-authoritative.
