# Custom plot color runtime (2026-10-07)

- Root cause: the old cosmetic loop marked only PlotPlatform and changed BasePart.Color. The platform merges its navy foundation, porcelain lip and green inset lawn into one palette-atlas MeshPart (assets/blender/env_builders.py: plot_platform). Neither the pink GrassSlab carpet nor the seven PlotFenceSection pieces and WoodenFence were marked. A saturated atlas cannot produce arbitrary bright hues by color multiplication.
- Creator Docs describe MeshPart.TextureID as a runtime-changeable texture and distinguish it from SurfaceAppearance/PBR maps: https://create.roblox.com/docs/reference/engine/classes/MeshPart and https://create.roblox.com/docs/parts/meshes . MeshId is not runtime writable; this fix reuses geometry and does not edit it.
- SurfaceAppearance.Color multiplies ColorMap. The released tinting announcement and subsequent TintMask client-beta announcement do not solve recoloring this existing saturated atlas without new neutral/masked art: https://devforum.roblox.com/t/full-release-surfaceappearance-tinting/3129960 and https://devforum.roblox.com/t/client-beta-introducing-tintmask-for-surfaceappearance/3600497 . Current property/security reference: https://create.roblox.com/docs/reference/engine/classes/SurfaceAppearance . DevForum announcement bodies were bot-gated in this session; indexed release text was available.
- Chosen method: reversible SmoothPlastic solid finish, cleared TextureID/MaterialVariant and temporarily unparented SurfaceAppearance/Texture/Decal objects on explicitly tagged render pieces only. Restore the original objects and all original finish properties for Default, lost entitlement and plot release. Instance parenting/attributes/descendants: https://create.roblox.com/docs/reference/engine/classes/Instance ; color/material: https://create.roblox.com/docs/reference/engine/classes/BasePart . This adds no render meshes, triangles, remotes, asset requests or per-frame loops. The Blender silhouette/bevels remain; custom plots deliberately replace baked palette detail with coordinated solid colors. No new Blender template/upload is needed.
- UI selection uses supported UIStroke.Enabled and Color3:Lerp/fromRGB APIs: https://create.roblox.com/docs/reference/engine/classes/UIStroke and https://create.roblox.com/docs/reference/engine/datatypes/Color3 . Ownership remains server-derived using the existing MarketplaceService flow: https://create.roblox.com/docs/reference/engine/classes/MarketplaceService .
- Runtime path was already correct: PlotColor -> Rules.SetPlotColor -> Settings.PlotColor -> sync -> MonetizationService.Apply -> CosmeticService.Apply; State includes Settings. Existing ownership, allowed-ID, extra-argument, profile-lease and token-bucket checks remain unchanged. DataService sanitization/save and rebirth replacement retain the preference.
- Rojo v7 build workflow: https://rojo.space/docs/v7/getting-started/new-game/ . StyLua Windows line endings/check: https://github.com/JohnnyMorganz/StyLua . Formatting is checked, not inferred from CLI success alone (prior override regression: https://github.com/JohnnyMorganz/StyLua/issues/925).
