# Huge resort runtime research — 2026-10-05

Current official pages and the platform announcement were checked before implementation. Numbers below are our project choices, not Roblox guarantees.

- **Streaming:** minimum radius is priority/retention, target is desired coverage rather than a guaranteed visible distance. Atomic streams compact models together; do not make the whole island Atomic or Persistent. Use min 128 / target 512, `PauseOutsideLoadedArea`, and `RequestStreamAroundAsync` before distant travel. ReplicatedStorage templates still cost client memory. [Streaming](https://create.roblox.com/docs/workspace/streaming).
- **Bounded distant silhouette:** the implemented skyline reserves 25 Persistent single-mesh models, 21,186 source triangles, for the landmark, mountains, clouds and islets. This is an intentional artistic exception; all playable island modules stream normally. Do not assume engine-generated model LOD exists for this runtime assembly without a Studio/published-client check. [Model streaming modes and SLIM requirements](https://create.roblox.com/docs/workspace/streaming).
- **Current platform changes:** the April 2026 announcement describes scene-importance mesh streaming and improved cloud LODs. Do not force newer opt-in flags against an older Rojo reflection database, nor assume Automatic means all distant props are always visible. [Creator updates](https://create.roblox.com/updates), [Roblox announcement, indexed; direct DevForum body unavailable](https://devforum.roblox.com/t/introducing-mesh-streaming-and-improved-cloud-lods-in-published-experiences-opt-in-phase/4601232/).
- **Pivots:** place normalized cached models through `PivotTo`; `ScaleTo` preserves model-relative relationships. Remove imported staging CFrames, retain the verified Y-up/front PivotOffset, and normalize to independent manifest bounds. Only structural surface variants deliberately stretch after normalization. [PVInstance](https://create.roblox.com/docs/reference/engine/classes/PVInstance), [Model](https://create.roblox.com/docs/reference/engine/classes/Model).
- **Mesh fidelity/collision:** Automatic render fidelity is serialized in both imports. CollisionFidelity is not a safe runtime write; disable mesh collisions and provide simple anchored invisible boxes. Imported PhysicalConfigData is opaque to our Rojo inspection; Box mesh fidelity still requires Studio edit-time verification/resave. [MeshPart](https://create.roblox.com/docs/reference/engine/classes/MeshPart), [performance/collision guidance](https://create.roblox.com/docs/performance-optimization/improve).
- **Large worlds:** reuse identical mesh/texture content, keep spatial modules small, suppress shadow/query/touch work for decoration, and avoid server per-frame transforms. Source triangle totals and headless budgets cannot certify phone frame rate. [Performance](https://create.roblox.com/docs/performance-optimization/improve).
- **Effects:** use occluded Highlights on Epic+ rewards; avoid nested highlights. Beams require two attachments and permit texture-free colored glow. Trails suit moving objects; static castle rays use Beams instead. Keep effects small because mobile overdraw matters. [Highlight](https://create.roblox.com/docs/reference/engine/classes/Highlight), [Beams](https://create.roblox.com/docs/effects/beams), [Trail](https://create.roblox.com/docs/reference/engine/classes/Trail).
- **World text:** finite MaxDistance for SurfaceGui/BillboardGui, no AlwaysOnTop for public labels, no RichText interpolation of player names, and 10-second ranking refresh rather than Heartbeat. Distance limits reduce clutter; actual GPU costs still require profiling. [BillboardGui](https://create.roblox.com/docs/reference/engine/classes/BillboardGui), [SurfaceGui](https://create.roblox.com/docs/reference/engine/classes/SurfaceGui).
- **SurfaceGui culling:** the platform announcement introduced distance culling for world surfaces; use it on boards, signs and collect pads instead of allowing all text surfaces to remain visible across the island. [DevForum announcement](https://devforum.roblox.com/t/new-surfaceguimaxdistance-property/2574715).
- **Tooling:** Rojo `$path` maps the single .rbxm root to ReplicatedStorage; binary import integrity is checked through Rojo XML. StyLua checks the same Luau source used by production. [Rojo project format](https://rojo.space/docs/v7/project-format/), [StyLua](https://github.com/JohnnyMorganz/StyLua).
