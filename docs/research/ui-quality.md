# UI quality research — 2026-10-05

Read before implementation; reference images inspected: `quality-reference-1.webp` and `mockups.png`.

- **Typography:** `FredokaOne` and `LuckiestGuy` are supported Enum fonts. Gotham/GothamBlack are removed and map to Montserrat. Use Fredoka for UI, LuckiestGuy sparingly for celebration headings. [Font enum](https://create.roblox.com/docs/reference/engine/enums/Font)
- **Outlines:** UIStroke Contextual outlines glyphs; Border outlines controls. Use one text stroke with TextStrokeTransparency=1, fixed 2px text/3px control strokes; do not animate glyph stroke thickness. [UIStroke](https://create.roblox.com/docs/reference/engine/classes/UIStroke), [Roblox engineering explanation](https://devforum.roblox.com/t/uistroke-studio-beta-update-re-enabled/1116289)
- **Chrome:** white Frames with a two-stop vertical UIGradient, UICorner, inset highlight and offset dark shadow. UIGradient does not apply to children; animate Offset for a shine instead of rebuilding sequences. Rounded corners do not replace clipping. [UIGradient](https://create.roblox.com/docs/reference/engine/classes/UIGradient), [UICorner](https://create.roblox.com/docs/reference/engine/classes/UICorner)
- **Sizing:** UIScale scales a subtree and suits short press/pop animations. UIAspectRatioConstraint keeps icons square; do not apply it to a whole adaptive panel or fight a layout's cell sizes. UIListLayout/ UIGridLayout own child positions; AutomaticCanvasSize supports scrollable content. [Size modifiers](https://create.roblox.com/docs/ui/size-modifiers), [UIListLayout](https://create.roblox.com/docs/reference/engine/classes/UIListLayout), [UIGridLayout](https://create.roblox.com/docs/reference/engine/classes/UIGridLayout)
- **Safe areas:** ScreenInsets=CoreUISafeInsets protects top-bar controls and notches. Measure a full-size child Frame's AbsoluteSize, rather than subtracting guessed insets from Camera.ViewportSize. GuiService:GetGuiInset is available, but mixing it with ScreenInsets double-insets content. [ScreenGui](https://create.roblox.com/docs/reference/engine/classes/ScreenGui), [GuiService](https://create.roblox.com/docs/reference/engine/classes/GuiService), [2025 notch bug report](https://devforum.roblox.com/t/viewportsize-actual-screensize-due-to-notch-inset-screenguiscreeninsets-gets-overwritten-when-cloned-from-startergui-playergui/3848596)
- **Animation:** TweenService Back/Out for modal entrances, Quad for hover/press and number interpolation. Cancel superseded tweens. CanvasGroups allocate intermediate textures and may go blank under texture limits; avoid nested/full-screen CanvasGroups and use ordinary Frames plus UIScale here. [TweenService](https://create.roblox.com/docs/reference/engine/classes/TweenService), [CanvasGroup reference](https://create.roblox.com/docs/reference/engine/classes/CanvasGroup), [memory discussion](https://devforum.roblox.com/t/is-it-a-bad-idea-to-put-scrollingframes-in-canvas-groups/2803306)
- **Input:** GuiButton.Activated supports mouse, touch and gamepad. ContextActionService BindAction's createTouchButton flag creates a separate default touch control; use false when supplying a custom action button. Existing E/gamepad prompt remains the keyboard path; custom FLUSH uses the existing no-argument Flush remote, avoiding duplicate E dispatch. ProximityPrompt InputHoldBegin/End supports custom prompts. [GuiButton](https://create.roblox.com/docs/reference/engine/classes/GuiButton), [ContextActionService](https://create.roblox.com/docs/reference/engine/classes/ContextActionService), [ProximityPrompt](https://create.roblox.com/docs/reference/engine/classes/ProximityPrompt)
- **Images:** ImageLabel.IsLoaded can gate hiding the primitive fallback; empty/zero IDs must not replace it. Use ScaleType.Fit. All content strings come from Assets, with no fabricated IDs. [ImageLabel](https://create.roblox.com/docs/reference/engine/classes/ImageLabel)
- **Purchase cards:** preserve existing server BuyPass flow and GetProductInfoAsync metadata; never display a placeholder configured price as a live purchasable price. [MarketplaceService](https://create.roblox.com/docs/reference/engine/classes/MarketplaceService)
- **Platform changes reviewed:** recent shadow/corner APIs and styling transitions exist, but the shared chrome uses established Frames/UIStroke/UICorner and explicit tween cancellation for compatibility with this project's tooling. [Shadow/corner release](https://devforum.roblox.com/t/full-release-new-ui-capabilities-shadows-individual-corners/4636263), [2026 release notes 711](https://devforum.roblox.com/t/release-notes-for-711/4473831)
- **Tools:** build via Rojo CLI; StyLua supports Luau syntax and check mode; Selene requires the configured Roblox standard library. [Rojo repository](https://github.com/rojo-rbx/rojo), [StyLua](https://github.com/JohnnyMorganz/StyLua), [Selene configuration](https://kampfkarren.github.io/selene/usage/configuration.html)
- **Existing travel/audio paths:** keep local character PivotTo for the existing travel feature; select replicated hub/showcase anchors rather than hardcoded destination coordinates. SoundGroup.Volume mutes registered sounds together: connect DescendantAdded once and do one startup traversal, rather than scanning the world on each State. [PVInstance](https://create.roblox.com/docs/reference/engine/classes/PVInstance), [CFrame](https://create.roblox.com/docs/reference/engine/datatypes/CFrame), [SoundGroup](https://create.roblox.com/docs/reference/engine/classes/SoundGroup)
- **Short-screen panels:** ScrollingFrame.AutomaticCanvasSize manages content extent. Keep a minimum-height inner body and a pinned title/close bar; users can scroll the full body in short landscape while card grids retain readable text and 44px actions. [ScrollingFrame](https://create.roblox.com/docs/reference/engine/classes/ScrollingFrame)

## Layout decisions

One pure layout module defines pixel rectangles inside the safe area. Desktop uses left navigation, top travel tabs, bottom-left coins, center-bottom FLUSH/Auto, and right offers. Portrait uses smaller square navigation and separate bottom currency/action rows; offers collapse. Short landscape keeps both Roblox thumb-control corners clear and places actions between them. Modals suppress HUD interaction, use a centered bounded canvas and scroll their contents. The layout check covers 16:9, 19.5:9, portrait, tablet and asymmetric notch insets. Engine text rasterization, real touch gestures and GPU cost still require Studio/device QA.
