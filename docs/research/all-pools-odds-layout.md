# All-items odds and disclosure layout (2026-10-07)

- [Roblox Random.NextNumber](https://create.roblox.com/docs/reference/engine/datatypes/Random/NextNumber): uniform draws; production retains independent rare-first checks and the existing server RNG. Outcome probability is `check * product(1 - earlierCheck)`, not the independent check alone. Total luck still clamps to 10; each check clamps to 1.
- [TextLabel](https://create.roblox.com/docs/reference/engine/classes/TextLabel) and [TextService.GetTextSize](https://create.roblox.com/docs/reference/engine/classes/TextService#GetTextSize): size wrapped text against the available width and chosen Enum.Font/TextSize. Use a fixed readable font size, TextWrapped, top alignment, and no truncation; reserve scrollbar space. The disclosure measures each row and grows the list vertically instead of scaling text into fixed-height rows.
- [Automatic sizing guidance](https://create.roblox.com/docs/ui/size-modifiers): avoid combining TextScaled and AutomaticSize on the same text object. Only the containing list auto-sizes here; text rows have measured explicit heights.
- [DevForum wrapping/scroll report](https://devforum.roblox.com/t/textwrapped-does-not-work-correctly-with-automaticsize-scrollingframe/3483894) and [UIScale report](https://devforum.roblox.com/t/uiscale-breaks-textlabels-with-automaticsize-inside-of-a-scrollingframe/3101017): reported clipping makes reliance on automatic text heights alone unsuitable. These reports are evidence of possible issues, not proof about the current engine. Reflow on viewport width changes; one scroll viewport, zero initial canvas position. Headless tests approximate font metrics and do not certify native rendering.
- [Rojo build](https://rojo.space/docs/v7/getting-started/new-game/): `rojo build -o build.rbxl` produces a binary place.
- [StyLua options](https://github.com/JohnnyMorganz/StyLua): `line_endings = "Windows"` / `--line-endings Windows` retains CRLF. [Changelog](https://github.com/JohnnyMorganz/StyLua/blob/main/CHANGELOG.md) was checked for CLI override changes. No new engine feature or assumed bug fix is required.

No new Roblox API is used for RNG, income, persistence or remote authorization. No profile schema or ID changes are needed when eligibility is the entire catalog.

Release review: [Roblox release 741](https://devforum.roblox.com/t/release-notes-for-741/4906281), posted September 30, 2026, and the [release index](https://devforum.roblox.com/c/updates/release-notes/62) were checked. This change does not depend on a newly introduced UI feature or a presumed wrapping fix.
