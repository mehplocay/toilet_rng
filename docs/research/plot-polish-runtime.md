# Plot and hub polish runtime research — 2026-10-05

Checked current official references before changing the world. No asset IDs or network-loaded artwork were added.

- **Stable toilet base:** `Model:ScaleTo()` scales around the model pivot. Scale the normalized clone by its current scale times 2.75, preserving the shared foot datum; set the primitive fallback's pivot to that same datum first. Tier ornaments and imported staging transforms must not determine interaction distance. [Model / ScaleTo](https://create.roblox.com/docs/reference/engine/classes/Model/ScaleTo).
- **FLUSH detection:** prompts support BasePart, Attachment or Model parents. This project's client specifically requires a BasePart and measures distance to its Position. A separate invisible `FlushAnchor` at `plot.CFrame` gives client and server the same position, survives toilet animations and receives exactly one replacement owner-only prompt on a tier change. Home is 9 studs forward and 2.65 studs above that datum (9.38 studs away, inside the existing 10-stud prompt range). Existing server range, cooldown and authorization remain mandatory. [ProximityPrompt](https://create.roblox.com/docs/reference/engine/classes/ProximityPrompt), [server validation](https://create.roblox.com/docs/scripting/security/client-server-boundary).
- **Labels:** `BillboardGui.MaxDistance` is camera distance, not character distance. Empty/locked labels use an 18-stud camera limit; occupied labels use 65. This deliberately avoids a new client controller within the UI session's ownership, but a zoomed-out camera can hide nearby empty-slot labels. Public labels are occluded, with plain player-name text. The owner-only guidance billboard now receives the arch position through the existing `PlotSignPosition` attribute. [BillboardGui](https://create.roblox.com/docs/reference/engine/classes/BillboardGui).
- **Ambient motion:** reuse `VisualIdle`'s existing local tweens, 100-stud culling and destruction cleanup. Six islet meshes carry `IdleBob`, one coin model carries `IdleOrbit`, three portal lights carry `VisualIdle`, and the coin uses one 1/sec sparkle emitter. No server heartbeat or continuous server ambient tween was introduced. Distant/high islets can remain still until their mesh is within the client's existing distance limit. [TweenService](https://create.roblox.com/docs/reference/engine/classes/TweenService), [performance guide, including server tween replication](https://create.roblox.com/docs/performance-optimization/improve).
- **Upgrade glow:** ten existing curved kit segments make a real open-center ring. Each upgrade produces ten bounded 1.5-second size/color tweens; replacement upgrades and plot release cancel prior tweens and restore the authored geometry. These infrequent server tweens replicate to nearby clients, unlike the continuous client ambience. The work does not claim that a server tween is free.
- **Streaming:** retain the existing 25 Persistent skyline models; four extra clouds and two smaller nearby islets stream normally. Consolidate four grass render tiles into one 48-stud tile per existing collision cell, funding new scenery without widening the spatial streaming units. [Streaming](https://create.roblox.com/docs/workspace/streaming).
