# Upgrade / reveal merge integration

Checked 2026-10-05.

- Creator Hub's [client-server security guide](https://create.roblox.com/docs/scripting/security/client-server-boundary) requires server validation and rate limiting for client-triggered actions and explicitly calls out NaN. Keep the owner, live profile, finite distance and shared cooldown/limiter gates for manual, prompt and auto flushes. The 0.4-second floor needs 2.5 tokens/second; the merged bucket refills at 3/second with capacity 2.
- [TweenInfo](https://create.roblox.com/docs/reference/engine/datatypes/TweenInfo) defines repeats in addition to the initial play and optional reversal. Five repeats with reversal produce twelve legs; the world wobble uses duration / 12 per leg. World animation duration is min(0.9, cooldown * 0.8), including the floating drop. [TweenService](https://create.roblox.com/docs/reference/engine/classes/TweenService) provides the existing tween construction API.
- Consulted the [release notes index](https://create.roblox.com/docs/release-notes) (only an index pointer was exposed) and [DevForum discussion of completion callbacks](https://devforum.roblox.com/t/optimizing-tweenservice/3708914). No new engine behavior is assumed; existing completion callbacks retain cleanup without yielding the award path.
- The active tiered controller owns reveal playback. Ordinary reveals whose duration would reach the next cooldown become compact toasts; big reveals keep their normal duration, with at most two pending entries plus the active entry. Overflow becomes a toast. Keeping the legacy Reveal module's duration bound alone would not cover actual client startup.
- [Rojo build workflow](https://rojo.space/docs/v7/getting-started/new-game/) and [StyLua usage](https://github.com/JohnnyMorganz/StyLua) were checked for the requested build and formatting commands. Audit and UI runtime files require their PowerShell bundling harnesses; visuals and world harnesses share a generated filename and must run sequentially.
- [Selene's Roblox guide](https://kampfkarren.github.io/selene/roblox.html) requires the Roblox standard library. The installed 0.31.0 executable still lacks Roblox generation commands/support, and `selene src` fails before analysis because `roblox` is missing. Formatting, build and regression results do not imply a lint pass.
