# Client audio research

Checked 2026-10-05 before implementation. No audio IDs have been sourced.

- [Sound](https://create.roblox.com/docs/reference/engine/classes/Sound), [Sound objects](https://create.roblox.com/docs/sound/objects): non-positional music/UI sounds belong in SoundService; SoundId identifies content, IsLoaded/TimeLength indicate readiness, PlaybackSpeed changes pitch and duration, Looped repeats. Never wait indefinitely for Loaded on inaccessible assets.
- [SoundGroup](https://create.roblox.com/docs/reference/engine/classes/SoundGroup), [SoundService](https://create.roblox.com/docs/reference/engine/classes/SoundService): explicitly assign Sound.SoundGroup. Group gain multiplies individual sound gain; nested groups allow UI/reward/gameplay buses under a single SFX volume. Music gain is user volume multiplied by duck gain; deck gain is reserved for fades, avoiding double application of user volume.
- [EqualizerSoundEffect](https://create.roblox.com/docs/reference/engine/classes/EqualizerSoundEffect), [dynamic effects](https://create.roblox.com/docs/sound/dynamic-effects): effects may live on a SoundGroup. LowGain/MidGain/HighGain are band adjustments; use a modest high-band cut during major reveals and restore it afterward. Volume ducking remains the primary mix control.
- [TweenService](https://create.roblox.com/docs/reference/engine/classes/TweenService): numeric properties can be tweened; cancel the previous tween before retargeting the same property. Separate group fades from deck crossfades so Settings changes and overlapping events do not cancel track transitions.
- [ContentProvider](https://create.roblox.com/docs/reference/engine/classes/ContentProvider): PreloadAsync yields and accepts a completion callback with AssetFetchStatus. Preload only configured sounds, asynchronously in small batches; bound music readiness waits independently of preload completion. Failure must never hold up UI/profile loading.
- [Audio assets](https://create.roblox.com/docs/audio/assets), [asset privacy](https://create.roblox.com/docs/projects/assets/privacy): use licensed Creator Store audio or recordings with legal rights; uploads require moderation and experience usage permissions. Grant the production **universe**, including group-owned experiences, access through Creator Dashboard. Previewing an asset in Studio does not prove live access. Import limits currently include a single stream, supported audio formats, under 20 MB/7 minutes, and at most 48 kHz.
- [Permission bug discussion](https://devforum.roblox.com/t/some-audios-owned-by-group-not-working-in-group-owned-game/1746941): historical reports include group ownership failing to supply expected permissions. Treat these as deployment checks, not current guaranteed bugs; confirm permissions and test a published private server.
- [Audio](https://create.roblox.com/docs/audio), [AudioPlayer](https://create.roblox.com/docs/reference/engine/classes/AudioPlayer), [official beta-exit announcement](https://devforum.roblox.com/t/roblox-audio-api-exits-beta-enhanced-sound-controls-now-available/3153454): the newer API is released and uses AudioPlayer/Wire/AudioDeviceOutput and separate Audio effects. Current AudioPlayer.Asset replaces deprecated AssetId. This task deliberately uses documented Sound/SoundGroup compatibility with existing game sounds; no voice, occlusion or spatial graph is required.
- [Recent platform recap](https://devforum.roblox.com/t/weekly-recap-september-21-25-2026/4894110): the current search extract mentions enhanced realism with Sound support still in development; this concerns newer spatial features and does not establish removal of Sound playback. The live Sound reference still documents the methods used here.
- Mobile/autoplay: official Sound and AudioPlayer docs allow scripted/automatic playback; no browser gesture requirement is documented for native Roblox Sound. Start only after profile, game and character readiness, with a soft fade. Test iOS/Android device volume, silent mode, focus changes and interruptions in the real client; do not infer browser autoplay behavior. [Console guidelines](https://create.roblox.com/docs/production/publishing/console-guidelines) also recommend audio interaction feedback.
- Mobile performance design: keep at most two music decks and a bounded SFX voice pool, throttle hover/ticks, and skip empty IDs before allocation/preload. [Runtime discussion](https://devforum.roblox.com/t/efficient-ways-to-handle-sounds-at-runtime/3307856) and [preload discussion](https://devforum.roblox.com/t/how-to-preload-a-lot-of-sounds/3807017) corroborate first-play latency and selective preloading; these are community reports, not engine performance guarantees.
- [GuiObject input](https://create.roblox.com/docs/reference/engine/classes/GuiObject), [UserInputService](https://create.roblox.com/docs/reference/engine/classes/UserInputService), [InputObject](https://create.roblox.com/docs/reference/engine/classes/InputObject): sliders track one touch or mouse drag through global InputChanged/InputEnded, plus keyboard/controller step buttons. Persist a coalesced final value rather than every pointer movement.
- [DataModel](https://create.roblox.com/docs/reference/engine/classes/DataModel) documents IsLoaded for client startup; [RunService](https://create.roblox.com/docs/reference/engine/classes/RunService) documents Heartbeat for low-frequency mix updates. [SoundEffect](https://create.roblox.com/docs/reference/engine/classes/SoundEffect) effects are attached to the documented legacy mixer; no AudioPlayer effects are mixed into this graph.
- Tool checks: [Rojo build](https://rojo.space/docs/v7/getting-started/new-game/) documents binary build.rbxl output; [StyLua](https://github.com/JohnnyMorganz/StyLua) documents Luau formatting and --check; [Selene configuration](https://kampfkarren.github.io/selene/usage/configuration.html) requires the Roblox standard library for this project. Existing project runners bundle engine-dependent modules against test doubles; they cannot verify audible mixing or mobile audio behavior.
