# Offline composition previews

These are **Blender previews**, not Roblox Studio screenshots or successful upload tests.

`overview.png`, `spawn.png` and `plot.png` use the production builders with mocked mesh creation and the local authored Blender meshes. No Roblox mesh IDs are configured. Files ending in `-fallback.png` show the primitive world used with empty IDs.

The render approximates Terrain using a heightfield and differs in lighting, sky, font, random-number sequence and primitive tessellation. Roblox particles, streaming, UI, physics and content permissions are not represented. See [the handoff](../world-models.md) for generation commands, measured budgets and remaining Studio acceptance.
